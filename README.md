# E-Commerce Fullstack (C# + React)

Project belajar Fullstack E-Commerce menggunakan **C# (.NET)** untuk Backend dan **React** untuk Frontend.

---

## 🎯 Fitur Utama

- Sistem autentikasi (Register, Login)
- CRUD Product & Category
- Shopping Cart
- Checkout (dalam pengembangan)
- Responsive Design
- API dengan .NET
- Frontend modern dengan React

---

## 🛠️ Teknologi yang Digunakan

**Backend (API)**
- C# / .NET
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server / PostgreSQL (sesuai konfigurasi)

**Frontend (Client)**
- React.js
- TypeScript
- Axios / Fetch
- TailwindCSS atau CSS Framework lain (kalau pakai)

**Lainnya**
- Docker & Docker Compose
- GitHub Actions (CI/CD)

---

## 📁 Struktur Folder

e-commerceFullstack/
-API -> Backend(.NET 10)
-CLINET -> Frontend (React)
- docker-compose.yml
- .github/workflows -> CI/CD
- Readme.md

  ---

## 🚀 Cara Menjalankan Project

### 1. Clone Repository
- Bash
  git clone https://github.com/nopalbahq/e-commerceFullstack.git
cd e-commerceFullstack

### 2. Jalankan dengan Docker
docker-compose up --build

### 3. Run Manually
Backend:
cd API
dotnet restore
dotnet run

Frontend:
cd CLIENT
npm install
npm run dev
